# Mise Chatbot

## Setup

1. Install dependencies.

```bash
npm install
```

2. Start Ollama.

```bash
ollama serve
```

3. Start the Vite frontend.

```bash
npm run dev
```

## Environment Variables

- `VITE_OLLAMA_URL`: optional Ollama base URL for the browser client
